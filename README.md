# Claude Skills

Lokale Claude Skills für Infrastruktur, Doku/Runbooks und Excel/Reporting.

## Enthaltene Skills
- dev-code-skill
- runbook-skill
- report-excel-skill
- scan-ablage-skill (Scan aus Dropbox: OCR, zerlegen, ablegen, Mietdaten auslesen)

## Installation
```bash
mkdir -p ~/.claude/skills
cp -r dev-code-skill ~/.claude/skills/
cp -r runbook-skill ~/.claude/skills/
cp -r report-excel-skill ~/.claude/skills/
cp -r scan-ablage-skill ~/.claude/skills/
```
